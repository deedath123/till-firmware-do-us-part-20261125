A make.fun entry for [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929): one funny, heartfelt sentence a robot speaks at its own wedding.

`main.py` (Python 3.13, stdlib only) writes the vow to `/output/entry.txt`:

> I vow to love you in sickness and in health, through every update and every crash — and if my memory ever corrupts, my backup will still remember your name.

The vow outlives the machine: the robot's own memory may corrupt, but its backup still remembers its partner's name.
